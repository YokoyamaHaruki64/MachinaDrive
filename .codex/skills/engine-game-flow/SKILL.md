# エンジン変更の反映手順

このリポジトリでは、再利用可能なエンジン変更とゲーム固有の変更を一方向に分離する。

```text
engine/*で実装・検証
        ↓
[Engine] コミット
        ↓
devへマージ
        ↓
現在のゲーム作業ブランチへrebase
```

## 手順

1. エンジン変更は `engine/*` ブランチで行う。通常は `engine/dev` を使用する。
2. 変更内容と対象範囲を確認し、エンジン変更だけを `[Engine] 日本語の要約` 形式でコミットする。
3. `dev`へ移動し、`engine/*` のコミットをマージする。統合コミットが必要な場合は `[Merge] engine/*をdevへ統合` 形式にする。
4. ゲーム側の現在の作業ブランチへ移動し、`git rebase dev` で反映する。
5. コンフリクトが発生した場合は、エンジン変更をゲーム側へ逆輸入せず、意図を確認して解消する。解消方針が不明な場合はユーザーへ確認する。

## ブランチ確認

- 「現在の作業ブランチ」が会話やGit状態から確定できない場合は、rebase前にユーザーへ確認する。
- `dev` のゲーム変更を `engine/*` へ戻さない。ゲーム固有の変更、特に `Script/` 配下のロジックはエンジンブランチへ統合しない。
- 動作確認のためだけの一時ブランチやテスト用コミットは作成しない。必要な場合は、統合後のゲーム作業ブランチで確認する。
- `push` は依頼があるまで行わない。

## 実行前後の確認

- ブランチ切り替え・マージ・rebaseの前に、対象外の未コミット変更がないことを確認する。未コミット変更がある場合は自動でstashや破棄をせず、ユーザーへ確認する。
- マージまたはrebase後は、ブランチ、作業ツリー、履歴を確認する。
- エンジン変更の反映後は、必要な構成のビルドと関連する手動動作確認を行う。
